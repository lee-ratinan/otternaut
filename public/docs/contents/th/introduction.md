# ขอต้อนรับสู่ OtterNova

ยินดีต้อนรับสู่ **คู่มือการใช้งาน OtterNova** ไม่ว่าคุณกำลังจะเริ่มต้นตั้งค่าบริการแรกของร้าน หรือกำลังขยายทีมที่เติบโตขึ้น คู่มือฉบับนี้จะช่วยให้ธุรกิจของคุณพร้อมเปิดใช้งานและระบบดำเนินไปได้อย่างรวดเร็วภายในไม่กี่นาที

คุณสามารถใช้เมนูนำทางทางด้านซ้ายเพื่อศึกษาฟีเจอร์เฉพาะเจาะจงต่างๆ หรืออ่านข้อมูลภาพรวมอย่างรวดเร็วด้านล่างนี้เพื่อเริ่มต้นใช้งานได้ฟรีทันที

## ระบบหลัก

ระบบนิเวศของ OtterNova แบ่งออกเป็น 2 แพลตฟอร์มหลัก ได้แก่: ระบบหลังบ้านสำหรับบริหารจัดการ และหน้าร้านค้าออนไลน์สำหรับลูกค้า

### 🛠️ OtterPlex (แผงควบคุมหลัก)

นี่คือศูนย์บัญชาการธุรกิจส่วนตัวของคุณ ใช้สำหรับกำหนดค่าบริการ, ติดตามการจัดส่งสินค้า, จัดการสิทธิ์ของพนักงานในทีม และดูแลภาพรวมการดำเนินงานประจำวันทั้งหมด

- **ช่องทางเข้าสู่ระบบ:** <a href="https://client.otternova.com" target="_blank">https://client.otternova.com</a>
- **การเริ่มต้นใช้งาน:** เข้าสู่ระบบด้วยบัญชีที่ลงทะเบียนไว้เพื่อเข้าใช้งานแผงควบคุม และคุณสามารถส่งคำเชิญให้พนักงานในทีมสร้างบัญชีผู้ใช้ของตนเองได้จากที่นี่

### 🛒 OtterMart (มาร์เก็ตเพลส)

นี่คือหน้ามาร์เก็ตเพลส และหน้าจองบริการสำหรับลูกค้าทั่วไป คุณสามารถนำลิงก์นี้ไปใส่ไว้ในโปรไฟล์โซเชียลมีเดียต่างๆ ของธุรกิจ เพื่อเพิ่มยอดผู้เข้าชม ค้นหากลุ่มลูกค้าเป้าหมาย และเปิดรับการจองโดยตรงได้ทันที

- **ลิงก์หน้าร้านค้าของคุณ:** <a href="https://mart.otternova.com" target="_blank">https://mart.otternova.com</a>
- **ฟีเจอร์เด่น:** แสดงข้อมูลร้าน ข้อมูลการติดต่อ แผนที่ร้าน รายการสินค้าเพื่อจัดจำหน่าย และระบบนัดหมายจองเวลาของลูกค้าแบบอัตโนมัติ
